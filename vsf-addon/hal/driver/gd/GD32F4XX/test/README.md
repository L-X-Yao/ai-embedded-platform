# GD32F4XX port 主机模型

这份 port 目前没有板子跑（见 `../README.md`），错误的修复事后抓不到，所以每个修复都把证据留在这里：
先让模型在旧代码上失败，再修，再通过。

```bash
./run.sh            # 全部外设
./run.sh flash i2c  # 指定外设
```

需要 gcc，带 ASan/UBSan，`-Wall -Wextra -Werror`。

- `run.sh` 把 `common/` 里真实的 `.c`/`.h` 原样拷到临时目录再编译，代码不做任何改写。
- `host/` 是替身：`hal/` 代替 VSF 头文件，`vendor/` 是寄存器模型，位定义来自用户手册。
- `test_<外设>.c` 是外设模型加用例。用例名带审计编号，期望值来自 GD32F4xx 用户手册 Rev3.0（CN）。

模型只代表手册写的行为，没有在芯片上验证过。通过说明代码符合我们对手册的理解，不等于上板能跑。

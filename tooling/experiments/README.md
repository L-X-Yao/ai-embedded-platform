# tooling/experiments/

Exploration scaffolds from VSF SIM investment period (2026-04-22/23). Retained as reference for future sim/QEMU work.

## Directories

| Directory | Purpose | Status | Reference |
|-----------|---------|--------|-----------|
| `vsf-tryouts/kernel_test/` | VSF linux64 kernel-only sim attempt | **Archived** — proved not viable (ADR-008 Option A) | Triage baseline; reuse if linux64 revisited |
| `vsf-tryouts/mps2_bare/` | VSF mps2-an500 bare-metal sim (QEMU) | **First-class** — canonical sim path | ADR-008 Option C, proven working |
| `vsf-tryouts/linux_shell_size/` | POSIX overhead measurement on QEMU | **Archived** — measurement complete (+56KB Flash, +8KB RAM) | Referenced in CLAUDE.md |
| `build-kernel-test/` | CMake build output from kernel_test | **Stale artifact** — safe to delete, regenerated by cmake | .gitignore catches this |

## Maintenance

- Do NOT add new experiments here without documenting purpose and expected lifecycle
- Graduate successful experiments to `templates/` or proper tooling
- Archive failed experiments with a one-line "why it failed" note

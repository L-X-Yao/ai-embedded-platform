# wheels/drivers/ — L1 硬件驱动

具体芯片/传感器/外设的驱动，通过 VSF HAL 跨 MCU。

**命名**：按芯片/器件型号，不按"LED 驱动"这种泛称。
- ✅ `mpu6050/`（六轴传感器）
- ✅ `w25q64/`（SPI flash）
- ✅ `lcd_st7789/`（LCD 控制器）
- ❌ `display/`（泛名，不同芯片差异大）

**合格门槛**（L1）：
- sim 里有 mock 测试（模拟硬件行为）
- 至少 1 次真机验证记录（写入 README 的"支持的平台"节，含日期）
- 所有硬件访问必须走 VSF HAL，**禁止**直接操作寄存器

## 典型 wheel 候选（按项目触发新建）

**传感器**：MPU6050 / BME280 / BH1750 / DS18B20  
**存储**：W25Q64 / AT24C02 / SD 卡  
**显示**：ST7789 / SSD1306 / ILI9341  
**无线**：ESP-AT（WiFi 模组）/ 蓝牙模组  
**其他**：PCF8574（IO 扩展）/ TM1637（数码管）
